# Новогодний стол

Сайт-меню для новогоднего стола. Вы указываете, какие продукты есть дома, а сайт показывает блюда в четырёх разделах (закуски, первое, второе, десерты) и подсказывает, чего не хватает.

## Возможности

- Список продуктов: добавлять и убирать можно в любой момент.
- Для каждого блюда видно, какие ингредиенты есть, а какие нужно докупить.
- Фильтр: все блюда, не хватает до 2 продуктов, всё есть.
- «Моё меню»: выбранные блюда и общий список покупок с кнопкой копирования.
- Новогоднее оформление: гирлянда, снег, отсчёт дней до Нового года, светлая и тёмная тема.

## Запуск

Сайт состоит из одного файла `index.html`, сборка не нужна. Откройте файл в браузере.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него `index.html` и `README.md`.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через минуту-две сайт появится по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Как изменить данные

Все рецепты лежат в массиве `RECIPES` внутри `index.html`. Для нового блюда скопируйте любой элемент массива и поменяйте поля:

- `cat` — раздел: `zakuski`, `pervoe`, `vtoroe` или `desert`;
- `art` — рисунок: `fish`, `mushroom`, `drumstick`, `roast`, `soup`, `potato`, `salad`, `tartlet`, `glass` или `fruit`;
- `ings` — ингредиенты: `I(название, количество, основы для поиска через |, ключ для списка покупок, 1 для домашнего запаса)`.

Стартовый список продуктов задан в массиве `DEFAULTS`.

## Примечания

- Список продуктов и выбранное меню хранятся в браузере (`localStorage`) на том устройстве, где открыт сайт.
- Шрифты Nunito и Yeseva One подгружаются с Google Fonts. Без интернета сайт откроется, но с системными шрифтами.
- Фотографии блюд на сайт не встроены. В каждой карточке есть ссылка на оригинал рецепта с фото.
